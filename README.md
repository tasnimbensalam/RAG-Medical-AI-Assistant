# RAG-Medical-AI-Assistant
J'ai suivi un tutoriel YouTube de sn dev pour construire un Medical Assistant Chatbot, basé sur un pipeline full-stack RAG (Retrieval-Augmented Generation)
Le projet combine :

LangChain pour orchestrer le pipeline
Pinecone comme base de données vectorielle
Google Embeddings pour la vectorisation du texte
Groq (LLaMA 3) comme modèle de langage

L'objectif : créer un chatbot intelligent et spécialisé capable de répondre à des questions médicales en s'appuyant sur de vrais documents PDF.
